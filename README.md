# Skillissue M+ Helper

Skillissue M+ Helper is a World of Warcraft addon with useful quality-of-life tools for Mythic+ and raid content.

## Features

### Automatic combat logging

The addon can automatically start combat logging when you enter selected content:

- Mythic dungeons
- Mythic+ dungeons
- Normal raids
- Heroic raids
- Mythic raids
- Raid Finder

You can choose which instance types should trigger combat logging.

### Warcraft Recorder compatibility

Enable this option to delay stopping combat logging for 30 seconds after leaving an instance. This can help Warcraft Recorder finish processing the current recording.

### Automatic repair

When enabled, the addon automatically repairs damaged equipment after you open a repair merchant.

Guild repair funds are used when available. Otherwise, the addon uses your own gold only when you can afford the complete repair cost.

### Settings window

The settings window includes pages for:

- General settings
- Quality of Life
- Buff Reminder
- Utility Helper

The window can be moved and resized.

## Installation

1. Download and extract the addon archive.
2. Make sure the addon folder is named `SMhelper`.
3. Copy the folder to:

   ```text
   World of Warcraft/_retail_/Interface/AddOns/
   ```

4. Restart World of Warcraft or reload the interface.
5. Enable **Skillissue M+ Helper** in the AddOns menu on the character-selection screen.

## Usage

Open or close the settings window with either command:

```text
/smhelper
/smh
```

## Saved settings

Your settings are saved automatically between game sessions.
