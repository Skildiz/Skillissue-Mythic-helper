# SMHelper

Special addon created for your progress in m+

## Install

Copy the `SMhelper` folder into `World of Warcraft/_retail_/Interface/AddOns/`, then restart or reload the game.

Commands: `/smhelper` or `/smh`.

The window header reads `Skillissue M+ helper`. The sidebar contains General, Quality of Life, Buff Reminder, and Utility helper. The active button is highlighted with a blue glow. Drag the bottom-right grip to resize the menu.
